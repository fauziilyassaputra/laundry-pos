# 🧺 Laundry POS - Management System

A modern, high-performance Point of Sale (POS) web application specifically designed to streamline laundry business operations. This system simplifies order recording, real-time status tracking, and workflow management for managers, cashiers, and operators.

🔗 **Live Demo:** [laundry-pos-sooty.vercel.app](https://laundry-pos-sooty.vercel.app)

---

## 🛠️ Tech Stack & Libraries

Built with a cutting-edge frontend stack to ensure a fast, interactive, and scalable user experience:

* **Framework:** [Next.js](https://nextjs.org/) (App Router)
* **Data Fetching & State Synchronization:** [TanStack React Query](https://tanstack.com/query/latest)
* **Global State Management:** [Zustand](https://docs.pmnd.rs/zustand/getting-started/introduction)
* **UI Components & Styling:** [shadcn/ui](https://ui.shadcn.com/) & Tailwind CSS
* **Form Management:** [React Hook Form](https://react-hook-form.com/)
* **Schema Validation:** [Zod](https://zod.dev/)
* **Database & Auth:** [Supabase](https://supabase.com/)
